# FlowPilot AI frontend reference

The attached product reference is the visual source of truth for the frontend redesign. The primary implementation target is the **Hybrid — Sidebar Dark + Light Workspace** treatment: a navy navigation rail, white/light workspace surfaces, compact KPI cards, clear chart panels, and restrained blue/green accents.

## Applied design direction

- Dark navy sidebar remains the persistent navigation and identity surface.
- Workspace uses a light canvas, white cards, slate typography, subtle borders, and soft shadows.
- Existing API-backed values remain the only source for dashboard metrics, task lists, projects, and employees.
- Shared controls (buttons, forms, badges, stat cards, page headers, and user menu) use the same light visual language.
- Motion is limited to short entrance/hover transitions and respects `prefers-reduced-motion`.

`flowpilot-dashboard-reference.png` is a local visual reference asset for future UI review.
